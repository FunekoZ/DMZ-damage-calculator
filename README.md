# DMZ 枪械词条与 TTK 计算器

这个工具的主要目标是：

1. 评估不同交战场景、护甲、射程和命中分布下，枪械应选择什么词条才能获得最佳击杀枪数或 TTK。
2. 检查玩家自己已有的单词条或双词条组合，能够达到怎样的击杀枪数与 TTK。
3. 对比单伤与双伤词条的实际收益，而不是只比较纸面单发伤害。

工具支持护甲品质与覆盖类型、命中部位、射程、多弹丸、低品质词条、随机命中期望及 TTK，并可直接双击打开运行。

## 运行

直接打开 [index.html](index.html) 即可使用，不需要安装依赖或启动服务器。

## 项目文件

- [index.html](index.html)：完整前端与计算逻辑，可离线运行。
- [weapons.json](weapons.json)：枪械配置源文件，便于快速修改或新增枪械。
- [sync_weapons.py](sync_weapons.py)：将枪械配置同步进单文件前端。
- [README.md](README.md)：项目规则与维护说明。

修改 [weapons.json](weapons.json) 后运行：

```bash
python sync_weapons.py
```

然后重新打开或刷新 [index.html](index.html)。

## 枪械配置

```json
{
  "name": "Fennec (究极弹匣)",
  "shot_interval_ms": 54,
  "projectiles_per_shot": 2,
  "damage_ranges": [
    { "min": 0, "max": 8.7, "damage": 23 }
  ],
  "region_multipliers": {
    "head": 1.3,
    "upper_chest": 1.2,
    "abdomen": 1.05,
    "upper_arm": 1.0,
    "lower_arm": 1.0,
    "legs": 0.8
  }
}
```

字段：

- `name`：枪械名称。
- `shot_interval_ms`：射击间隔，单位毫秒。
- `projectiles_per_shot`：每次开火的弹丸数，短剑和喷子可配置，默认 `1`。
- `damage_ranges`：射程分段伤害，区间为 `min ≤ 距离 < max`。
- `region_multipliers`：各命中部位倍率。

## 基础规则

- 人物生命值：`100`。
- 每格护甲：`50`。
- 护甲品质：紫、橙、红、究。
- 品质差对应护甲倍率：`0.5、0.7、0.85、1.0、1.1、1.2、1.3`，上下限分别为 `0.5` 和 `1.3`。
- 护甲倍率只作用于护甲伤害，不作用于直接生命伤害。
- 击破护甲的一颗子弹会拆分计算护甲部分和血量部分。
- 平均期望开火次数最终向上取整。
- `TTK = (击杀开火次数 - 1) × 射击间隔`。

## 击破护甲的子弹与词条计算

设：

- `a`：应用射程、命中部位和倍率词条后的当前子弹伤害
- `x`：该颗子弹命中前的剩余护甲值
- `M`：枪械品质对当前护甲品质的护甲伤害倍率

护甲未被击破时：

```text
护甲伤害 = a × M
```

若该颗子弹击破护甲，用于消耗剩余护甲的等效基础伤害为：

```text
击破护甲所需伤害 = x ÷ M
击破后的血量伤害 = a − x ÷ M
```

不同词条在击破弹上的处理：

- **部位倍率词条**：先计算对应部位的词条倍率，得到 `a`，再按击破公式拆分。双倍率词条的增减值相加，例如两个 `+0.2` 得到 `1.4` 倍。
- **破甲**：先将护甲按低一级品质取得新的 `M`，再使用 `a − x ÷ M`。橙品质破甲只在命中上胸或腹部护甲时有效。
- **肉伤**：护甲未破时额外造成 `a × 0.1` 血量伤害；击破时额外肉伤为 `x × 0.1`，击破后的剩余普通伤害不再乘 `0.1`。
- **橙品质肉伤**：先让该颗子弹的护甲伤害降低 `10%`，再计算护甲是否击破和额外肉伤。
- **未覆盖部位**：整颗子弹直接扣血，不触发破甲和肉伤。

## 护甲类型


| 护甲      | 类型   |
| ----------- | -------- |
| 紫甲 1 格 | 全包甲 |
| 紫甲 2 格 | 半包甲 |
| 紫甲 3 格 | 躯干甲 |
| 橙甲 2 格 | 全包甲 |
| 橙甲 3 格 | 半包甲 |
| 红甲 3 格 | 全包甲 |
| 红甲 4 格 | 半包甲 |
| 究甲 4 格 | 全包甲 |
| 究甲 6 格 | 全包甲 |

- 全包甲保护全身。
- 半包甲不保护腿部。
- 躯干甲只保护上胸和腹部。
- 命中未覆盖区域时，完整伤害直接扣血，护甲保持不变。

## 命中部位

- 头部
- 上胸
- 腹部
- 上臂
- 下臂
- 腿部

躯干 = 上胸 + 腹部；手臂 = 上臂 + 下臂；上半 = 躯干 + 手臂。

随机命中子弹会插入预计射击序列，逐颗随机顺序模拟，默认执行 `4000` 次并取向上取整后的期望开火次数。

## 词条

高品质词条：

1. 上半0.2：上半 `+0.2`，腿部 `-0.2`
2. 躯干0.2
3. 手臂0.2
4. 头部0.3
5. 头部0.5：头部 `+0.5`，其他 `-0.2`
6. 腿部0.2
7. 破甲：命中护甲按低一级品质计算
8. 肉伤：命中护甲时额外造成生命伤害

橙品质词条：

- 上半0.1：上半 `+0.1`，腿部 `-0.2`
- 躯干0.1
- 手臂0.1
- 腿部0.1
- 头部0.1
- 头部0.3：头部 `+0.3`，其他 `-0.1`
- 破甲仅命中上胸或腹部护甲时生效
- 肉伤先令该颗子弹的护甲伤害降低 `10%`，再处理肉伤

紫品质无法拥有词条，只计算无词条结果。

## 多弹丸

每颗子弹单独计算伤害与击破顺序，但最终枪数按开火次数计算。同一次开火中，前一颗子弹击破护甲后，后一颗子弹按无甲状态继续结算。

随机命中数量表示子弹颗数，而不是开火次数。

## 推荐命中预设

- Fennec 两种配置：正面对枪 + 常规对枪。
- Type19 (步枪)：正面对枪 + 常规对枪。
- Type19 (单点)：正面对枪 + 长枪单点。
- AS VAL 两种配置、SO-14：背面偷袭 + 长枪单点。
