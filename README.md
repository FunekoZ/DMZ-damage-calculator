# DMZ 击杀枪数计算器

一个可直接双击打开的单页枪械伤害计算器，支持护甲品质、覆盖类型、命中部位、词条、射程、多弹丸、随机命中期望与 TTK。

## 运行

直接打开 [index.html](index.html) 即可使用，不需要安装依赖或启动服务器。

## 项目文件

- [index.html](index.html)：完整前端与计算逻辑，可离线运行。
- [weapons.json](weapons.json)：枪械配置源文件，便于快速修改或新增枪械。
- [sync_weapons.py](sync_weapons.py)：将枪械配置同步进单文件前端。
- [README.md](README.md)：项目规则与维护说明。

修改 [weapons.json](weapons.json) 后运行：

```bash
python sync_weapons.py
```

然后重新打开或刷新 [index.html](index.html)。

## 枪械配置

```json
{
  "name": "Fennec (究极弹匣)",
  "shot_interval_ms": 54,
  "projectiles_per_shot": 2,
  "damage_ranges": [
    { "min": 0, "max": 8.7, "damage": 23 }
  ],
  "region_multipliers": {
    "head": 1.3,
    "upper_chest": 1.2,
    "abdomen": 1.05,
    "upper_arm": 1.0,
    "lower_arm": 1.0,
    "legs": 0.8
  }
}
```

字段：

- `name`：枪械名称。
- `shot_interval_ms`：设计间隔，单位毫秒。
- `projectiles_per_shot`：每次开火的弹丸数，短剑和喷子可配置，默认 `1`。
- `damage_ranges`：射程分段伤害，区间为 `min ≤ 距离 < max`。
- `region_multipliers`：各命中部位倍率。

## 基础规则

- 人物生命值：`100`。
- 每格护甲：`50`。
- 护甲品质：紫、橙、红、究。
- 品质差对应护甲倍率：`0.5、0.7、0.85、1.0、1.1、1.2、1.3`。
- 护甲倍率只作用于护甲伤害，不作用于直接生命伤害。
- 击破护甲的一颗子弹会拆分计算护甲部分和血量部分。
- 平均期望开火次数最终向上取整。
- `TTK = (击杀开火次数 - 1) × 射击间隔`。

## 护甲类型

| 护甲 | 类型 |
|---|---|
| 紫甲 1 格 | 全包甲 |
| 紫甲 2 格 | 半包甲 |
| 紫甲 3 格 | 躯干甲 |
| 橙甲 2 格 | 全包甲 |
| 橙甲 3 格 | 半包甲 |
| 红甲 3 格 | 全包甲 |
| 红甲 4 格 | 半包甲 |
| 究甲 4 格 | 全包甲 |
| 究甲 6 格 | 全包甲 |

- 全包甲保护全身。
- 半包甲不保护腿部。
- 躯干甲只保护上胸和腹部。
- 命中未覆盖区域时，完整伤害直接扣血，护甲保持不变。

## 命中部位

- 头部
- 上胸
- 腹部
- 上臂
- 下臂
- 腿部

躯干 = 上胸 + 腹部；手臂 = 上臂 + 下臂；上半 = 躯干 + 手臂。

随机命中子弹会插入预计射击序列，逐颗随机顺序模拟，默认执行 `4000` 次并取向上取整后的期望开火次数。

## 词条

高品质词条：

1. 上半0.2：上半 `+0.2`，腿部 `-0.2`
2. 躯干0.2
3. 手臂0.2
4. 头部0.3
5. 头部0.5：头部 `+0.5`，其他 `-0.2`
6. 腿部0.2
7. 破甲：命中护甲按低一级品质计算
8. 肉伤：命中护甲时额外造成生命伤害

橙品质词条：

- 上半0.1：上半 `+0.1`，腿部 `-0.2`
- 躯干0.1
- 手臂0.1
- 腿部0.1
- 头部0.1
- 头部0.3：头部 `+0.3`，其他 `-0.1`
- 破甲仅命中上胸或腹部护甲时生效
- 肉伤先令该颗子弹的护甲伤害降低 `10%`，再处理肉伤

紫品质无法拥有词条，只计算无词条结果。

## 多弹丸

每颗子弹单独计算伤害与击破顺序，但最终枪数按开火次数计算。同一次开火中，前一颗子弹击破护甲后，后一颗子弹按无甲状态继续结算。

随机命中数量表示子弹颗数，而不是开火次数。

## 推荐命中预设

- Fennec 两种配置：正面对枪 + 常规对枪。
- Type19 (步枪)：正面对枪 + 常规对枪。
- Type19 (单点)：正面对枪 + 长枪单点。
- AS VAL 两种配置、SO-14：背面偷袭 + 长枪单点。
